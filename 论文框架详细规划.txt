段落2: 现存问题与挑战
当前预测方法存在的主要困难：
1. 类别不平衡 (Imbalanced Classification)
   - 结合位点(正样本) << 非结合位点(负样本)
   - 传统模型倾向预测多数类
   - 难以获得足够的正样本

2. 域适应困难 (Domain Adaptation Gap)
   - 训练集vs测试集分布不一致
   - 跨数据集泛化性能下降
   - 例: 在DNA-573上训练好的模型在DNA-129上性能下降

3. 生成样本质量 (Generated Data Quality)
   - 简单过采样导致过拟合
   - 传统GAN生成质量难以保证
段落3: 相关工作综述
现有解决方案分类：
A. 数据层面
   - 过采样 (SMOTE, ADASYN)
   - 欠采样
   - 代价敏感学习
   - 扩散模型应用

B. 算法层面
   - 焦点损失 (Focal Loss)
   - 类别权重调整
   - 集成学习
   
C. 域适应方面
   - 迁移学习
   - 对抗域适应
   - 特征对齐
   
D. 现有局限性
   - 大多数方法未同时考虑增强质量 + 多样性
   - 缺乏严格的验证机制防止信息泄露
   - 域适应与不平衡学习的结合不足

3.2 扩散模型 (Diffusion Model)
推理过程 (Inference):
给定蛋白质上下文特征 c (如序列、结构信息)

前向扩散 (Forward Diffusion):
x_T = N(0, I)  // T步纯高斯噪声
x_t = √(ᾱ_t) * x_0 + √(1-ᾱ_t) * ε,  t=1...T
ᾱ_t = ∏(1-β_s)  // 累积乘积

反向去噪 (Reverse Diffusion):
x_{t-1} = (x_t - √(1-ᾱ_t)*ε_θ(x_t, c, t)) / √ᾱ_{t-1})
ε_θ: 神经网络预测噪声

生成正样本: x_0 = ε_θ(x_T, protein_context, T)
公式说明:
β_t: 方差调度 (variance schedule)
ε_θ: 条件噪声预测网络
c: 蛋白质上下文编码
3.3 质量-多样性数据增强
Step 1: 候选样本生成
────────────────────
从扩散模型生成 M = 3N_p 个候选样本
(过度生成用于后续筛选)

Step 2: 质量控制
──────────────
计算候选样本与真实正样本距离:
D = ||X_cand - X_real||_2  // 欧氏距离矩阵

min_dist_i = min_j(D_ij)  // 每个候选样本的最小距离

quality_score_i = 1 - (min_dist_i / max(min_dist))

保留: quality_score_i ≥ τ_q  (τ_q = 0.7)

Step 3: 多样性控制
──────────────
计算保留样本间距离:
similarity_ij = ||X_i - X_j||_2

对每个样本检查: min_j≠i(similarity_ij) ≥ τ_d
τ_d = 0.3 (多样性阈值)

贪心选择多样样本集合 D_diverse

Step 4: 最终选择
──────────────
取前 N_aug = min(|D_diverse|, max_ratio × N_p)
伪代码:
def quality_diverse_augmentation(X_cand, X_real, τ_q=0.7, τ_d=0.3):
    # 质量筛选
    distances = pairwise_euclidean(X_cand, X_real)
    min_dists = min(distances, axis=1)
    quality_scores = 1 - (min_dists / max(min_dists))
    X_quality = X_cand[quality_scores >= τ_q]
    
    # 多样性筛选
    diversity_dists = pairwise_euclidean(X_quality, X_quality)
    X_diverse = greedy_select(diversity_dists, τ_d)
    
    return X_diverse
3.4 域适应GNN
GNN架构:
────────
x^(l+1) = σ(W^(l) * AGG({x^(l)_j | j ∈ N(i)}) + b^(l))

损失函数:
────────
L_total = L_ce + λ * L_domain

L_ce: 二元交叉熵或焦点损失
      L_focal = -α(1-p_t)^γ * log(p_t)
      α=0.75, γ=2.0

L_domain: 域正则化
          L_domain = Var(σ(f_θ(x)))
          鼓励预测概率多样性 ↔ 特征分布一致

训练策略:
────────
K-Fold CV (K=3):
  For fold k:
    Train_k = Augmented_data ∪ Original_data\Test_k
    Val_k = Original_data_k
    
    重要: 验证集仅使用原始数据(防止增强数据污染)
3.5 集成预测
多模型集成:
──────────
选择CV中F1最佳的Top-N个模型
对测试集进行多数投票:

p_ensemble(y=1|x) = (1/N) * Σ_i p_i(y=1|x)
pred = argmax(p_ensemble)

好处:
- 降低单个模型的方差
- 提升预测稳定性
- 更好的泛化能力

4.3 评估指标
分类指标:
  • Precision = TP / (TP + FP)
  • Recall = TP / (TP + FN)  
  • F1-Score = 2 * (Precision * Recall) / (Precision + Recall)
  • MCC (Matthews Correlation Coefficient)
  • Balanced Accuracy = (TPR + TNR) / 2

排序指标:
  • AUC-PR (Area Under Precision-Recall curve)
    - 对不平衡数据集更敏感
  • AUC-ROC (Area Under ROC curve)
    - 整体判别能力

为什么选择这些指标:
  - F1 & MCC: 处理不平衡数据的经典指标
  - AUC-PR: 更关注少数类 (结合位点)
  - AUC-ROC: 全局评估能力

     ✓ 问题: 传统扩散模型虽能生成样本，但质量难以保证

       - 基础损失: 二元交叉熵 + 焦点损失 (关注难样本)
